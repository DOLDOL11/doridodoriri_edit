말풍선 만들기

발췌기 로그 정리

발췌기에서 복사한 코드를 상태창까지 통째로 붙여넣으면 블로그 본문 폭에 맞게 다시 짜 줘요.

발췌기 코드 → 블로그 HTML
🛰️

상태창 메이커

프리셋으로 상태창을 꾸며 HTML 코드나 PNG 이미지로 저장해요. 슬롯에 저장해 둔 상태창도 그대로 불러와요.

상태창 → HTML · PNG
📋

보고서 정리

AI가 출력한 보고서(OOC 분석 등)를 붙여넣으면 항목·수치·표를 나눠 보고서 양식으로 정리해 줘요. 양식 7종.

AI 보고서 → 블로그 HTML
🗂

캐릭터·프롬프트 보관함

AI 채팅 페르소나와 노벨AI 프롬프트를 사진과 함께 모아둬요. 카테고리·태그·검색, 버튼 하나로 복사.

페르소나 · 프롬프트 보관
🧩

콜라주 · 스티커

사진을 가로·세로·격자로 이어붙이고, 스티커와 글씨 라벨을 얹어 한 장으로 저장해요. 보관함 사진도 바로 불러올 수 있어요.

사진 → 콜라주 이미지
