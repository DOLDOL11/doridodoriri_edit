☁ GitHub 동기화

내 GitHub 비공개 저장소에 스튜디오 전체를 올리고, 다른 기기에서 받아와요. 열쇠(토큰)는 이 기기에만 저장되고 백업 파일에도 들어가지 않아요.

  1. GitHub에서 New repository → 이름(예: log-studio-data) → Private 선택 → Add a README 체크 → 만들기
  2. 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름 아무거나, 만료일 원하는 만큼 → Repository access: Only select repositories → 방금 만든 저장소 고르기
  4. Permissions → Repository permissions → Contents를 Read and write로 → 맨 아래 Generate token
  5. 나온 토큰(github_pat_로 시작)을 복사해서 위 칸에 붙여넣고 연결하기. 폰에서도 같은 저장소·토큰으로 한 번 연결해 주세요.
전체 백업
  • 말풍선·발췌기·보고서 작업 내용, 상태창 슬롯, 보관함(사진 포함), 로그 보관함, 홈 설정까지 파일 하나에 담겨요.
  • 다른 기기에서 불러오기로 열면 스튜디오 전체가 그대로 옮겨져요.
  • 브라우저 기록을 지우면 내용이 사라질 수 있으니 가끔 받아두세요.
